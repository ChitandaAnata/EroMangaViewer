# MangaShelf · 本地漫画书架

把你收藏的漫画压缩包整理成一个能打标签、能筛选、能直接翻页阅读的本地书架。
不上传、不联网、不要账号 —— 所有数据都留在你自己的电脑里。

**[⬇ 下载 MangaShelf-Setup.exe](https://github.com/ChitandaAnata/EroMangaViewer/releases/latest/download/MangaShelf-Setup.exe)**（约 67 MB，Windows 10 / 11）

---

## 安装与第一次使用

1. 双击 `MangaShelf-Setup.exe`，一路下一步（默认装到当前用户目录，不弹权限框）
2. 从开始菜单打开 **MangaShelf**
3. 点右上角齿轮 → **漫画库文件夹** → 选你放漫画的目录 → **保存并扫描**
4. 第一次扫描要给每本解压首图做封面，几百本大约一两分钟；之后都是增量扫描

把新漫画丢进库目录后，点一次右上角的 **刷新** 就会出现在书架上。程序不会自己盯着文件夹。

> 不需要装 Python、.NET 或任何解压软件。

## 书架

- **网格 / 列表** 两种视图，列表更紧凑、一屏看得更多
- **搜索框**同时搜书名和路径；空格分隔表示「都要满足」，输入 `7 9` 只显示书名里既有 7 又有 9 的作品
- 输入时还会弹出**标签联想**（如 `chi` → 「汉语 · language:chinese」），点一下才按标签筛选；光输入不点就是纯书名搜索
- 排序：最近添加 / 书名 / 页数 / 最近阅读
- 侧栏四个栏目：**全部作品**、**未进行标记**（一个标签都没打）、**更新中**、**Favorite**，数字实时更新
- 侧栏下面按分类列出标签，**勾一个看这类，勾多个取交集**；栏目和标签是叠加关系，比如「Favorite + 汉语」只看收藏里的汉语作品
- 分类标题可折叠，折叠状态会记住
- 卡片上直接看到作品分类、页数、标签和阅读进度条
- **右键卡片**：打开所在文件夹（自动选中文件）、复制文件路径

## 详情页

点封面先进详情页，不会直接开始读。

- **右上角「编辑模式」开关**，默认关闭。只读时页面上只有封面、分类、爱心、「开始阅读」和整本预览
- 打开后才会出现会改数据的入口：更新状态、编辑标签、改文件名、编辑系列
- **❤ 喜爱**按钮一直在「开始阅读」左边，点一下进侧栏 Favorite
- 整本按页展示缩略图，点任意一页就从那一页开始读
- **重置阅读进度**只在真读过之后出现，点它把进度清回第 1 页（不会直接跳进阅读器）
- 编辑模式下可以改**磁盘上的文件名**：源文件、数据库记录、旁边的 `.json` 一起改名，标签和进度都不丢
- 作品名后的下拉可以标「更新中」，之后出现在侧栏的更新中列表

## 标签

- 九个分类：语言 / 原作 / 角色 / 艺术家 / 社团 / 女性 / 男性 / 混合 / 其他
- 库里存原始名（`language:chinese`），界面显示中文名（「汉语」），互不干扰
- 常见语言自动翻译，也可以自己填显示名；标签自动配色
- 详情页 **＋ 编辑标签**：每个分类一个下拉，只列已有标签，选中即加入；缺的可以现场「＋ 新建标签」
- 增删改统一在 **设置 → 标签管理**；改名或删除会连同所有打了它的作品一起变

## 系列

同一个系列的多本作品串起来，顺序自己排。

- 详情页编辑模式 → **编辑系列** → 三个选择：**加入现有系列** / **新建系列**（起名后自动加入）/ **移出系列**
- 详情页会显示一行 `系列 · 第 N 话`，点它直接进系列页
- 系列页可以：**添加作品**（从库里搜 + 多选批量加入）、**↑↓ 调整顺序**、**解散系列**
- 系列名和顺序跟着文件走，换电脑重扫能完整恢复

## 阅读器

- **单页翻页**和**连续滚动**两种模式，设置里可改默认
- 自动记住看到第几页，下次接着看；关闭阅读器回到详情页
- 手机 / 平板上左右滑动翻页

| 按键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索框 |
| `←` `→` / `Space` | 上一页 / 下一页 |
| `Home` `End` | 第一页 / 最后一页 |
| `F` | 全屏 |
| `Esc` | 退出阅读器、逐级返回、关弹窗 |

左上角的 **返回** 是「后退一步」：从详情页点标签跳到筛选结果后，返回会回到那本书的详情页，而不是清空筛选。

## 作品分类

每本可以标一个类别，用来快速辨认。分类只有一个，标签可以很多，两套东西不冲突：

`Dojinshi` · `Manga` · `ArtistCG` · `GameCG` · `Non-H` · `ImageSet`

书架卡片放在书名前，详情页放在标题和标签之间；打开编辑模式点一下就能改。

## 设置

点顶栏齿轮进入独立设置页，首页是条目菜单，具体控件在子页里：

- **漫画库文件夹** —— 路径输入、浏览、保存并扫描
- **标签管理** —— 搜索 / 新建 / 改名 / 改显示名 / 删除
- **标签跟随文件** —— 旁挂开关、立即写出、清空全部标签
- **外观** —— 深色 / 浅色
- **关于** —— 版本与当前库信息

## 支持哪些文件

| 格式 | 说明 |
| --- | --- |
| `.zip` / `.cbz` | 最常用 |
| `.rar` / `.cbr` | 压缩存储的条目会自动改用系统自带的解压能力，不用装 WinRAR |
| `.7z` / `.cb7` | 同上 |

- 一个压缩包 = 一本漫画，**包内第一张图自动成为封面**
- 支持多层子文件夹，图片按自然顺序排（`2.jpg` 一定在 `10.jpg` 前面）
- 自动忽略 `__MACOSX`、`Thumbs.db` 之类的垃圾文件

## 数据放在哪，怎么迁移

标签、分类、状态、系列和阅读进度都**跟着文件走**：

```
你的漫画库/
├── mangashelf-tags.json      ← 全部标签的名字 / 分类 / 显示名 / 颜色
├── A作品/
│   ├── foo.cbz
│   └── foo.cbz.json          ← 这本的标签、分类、进度、系列
└── B作品/
    └── bar.cbz               ← 没整理过、没看过的不会有 json
```

**换电脑只要把整个漫画文件夹拷过去**，在新机器上重新指定库路径、扫描一次就全部恢复。
注意别在文件管理器里过滤掉 `.json`。

程序的运行数据（数据库、配置、封面缓存）在安装目录的 `data\`，删了也能从 json 重建。
卸载默认**只删程序、保留 `data\`**，重装后书架还在；想连数据一起清就勾「同时删除配置文件与阅读进度」。

## 手机上也能看

电脑和手机连同一个 Wi-Fi，把 `data\config.json` 里的 `host` 改成 `0.0.0.0` 并重启程序，
手机浏览器打开 `http://电脑局域网IP:8765`，再「添加到主屏幕」——之后就像独立 App 一样全屏打开。

> ⚠️ 开了 `0.0.0.0` 等于同一网络里谁都能读写，公共网络下不要这么做。

## 常见问题

**Q：新增的漫画没出现？**
点一次右上角「刷新」。程序不自动轮询文件夹。

**Q：某本封面显示「读取失败」？**
压缩包损坏、加密，或者里面没有图片。修好文件后再刷新一次。

**Q：卸载后重装，书架和标签还在吗？**
在。卸载默认只删程序，`data\` 和漫画库都不动。

**Q：桌面版和我用浏览器开的网页端会打架吗？**
不会。桌面版用安装目录下的 `data\`，网页端用项目目录下的，各存各的。

## 源码运行 / 自己打包

```bash
python app.py                # 网页端：浏览器打开 http://127.0.0.1:8765
```

依赖 `py7zr`、`rarfile`、`pillow`（Python 3.9+）。界面是原生 JS，改完 `web/` 刷新即可，没有构建步骤。

打包安装包（三步，只在定版时跑）：

```bash
python tools/build_backend.py      # PyInstaller 打 Python 后端
python tools/build_desktop.py      # 发布 C# 外壳 + 组装 dist/MangaShelf
python tools/build_installer.py    # 打 payload 并编译安装器 → MangaShelf-Setup.exe
```

`tools/test_*.py` 是接口与端到端回归，`tools/shot.py` 是界面截图。
桌面版外壳在 `desktop/`（C# WinForms + WebView2），安装器在 `installer/`（.NET Framework 4.8，系统自带）。
